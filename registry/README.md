# Reproducibility card registry

Cards document public comparisons backed by exact versions, commands/workflows, and an honest review
status. The registry is experimental until its schema and validation CLI are versioned.

Statuses:

- `fork-validated`: reproduced in a public fork or independent workflow, without upstream review;
- `upstream-reviewed`: maintainers reviewed the evidence or PR;
- `upstream-merged`: the work or documented conclusion was merged upstream.
